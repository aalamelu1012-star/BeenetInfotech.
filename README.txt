BEENET INFOTECH - MODERN PHP WEBSITE (V2)

HOW TO RUN
1. Install/start XAMPP Apache.
2. Copy the "beenet-modern" folder into C:\xampp\htdocs\
3. Open: http://localhost/beenet-modern/

V2 CHANGES
- Full-background hero slider with 3 slides
- Much richer homepage content based on the public Beenet website
- All major service categories represented
- Expanded About and Products pages
- How We Work, Customer Attention, Recent Blogs, domains, software features and full solution lists added
- Responsive desktop/tablet/mobile design
- Quote/contact submissions save to data/submissions.csv

NOTE
The site uses web-hosted images (Unsplash), Google Fonts and Font Awesome, so internet access is needed for those external assets.
